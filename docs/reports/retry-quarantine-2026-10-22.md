# 정기 BWIKI 재검증 실패 수정

실패 실행: [39782157427](https://github.com/moleculargastronomy1/hsrArchive/actions/runs/39782157427), `schedule`, 커밋 `78b6577f`.

사이트 빌드 명령 이전의 재검증 게시 단계가 실패했다. 후보의 기존 검증 손실 1건, 분기 연결 변경 7건, 기존 순서 변경 10건, 읽기 위치 손실 63건, 읽기 간선 손실 9건을 보존 검사가 차단했다. 따라서 실패 후보는 게시되지 않았으며 마지막 성공 배포가 유지됐다. 항목 수는 서로 겹칠 수 있다.

기존 재시도는 한 장의 BWIKI 후보가 이전 선택지/출현과 충돌하면 전체 후보를 거부했다. 같은 커밋의 새 공식 원문이 짧은 선택지의 동명 후보로 들어가거나 문서 재정합이 다른 독립 구간을 선택하는 경우 기존 링크를 대체하는 후보가 만들어질 수 있다. 이를 정답으로 확정하거나 검사 기준을 낮추지 않는다.

## 수정

- 회귀가 있는 장의 후보와 장별 근거를 격리하고 같은 공식 버전의 마지막 정상 본문 전체를 유지한다. 개별 간선만 합쳐 서로 다른 수정본/조건을 섞지 않는다.
- 검색 행과 장별 BWIKI·실행·영상 근거도 함께 보존한다. 이전 검증 코드/정책 해시를 기록하고 현재 새로 확인한 근거로 표시하지 않는다.
- 다른 장의 안전한 개선은 계속 검증하며, 복원 후에도 기존 공통 보존 검사와 최종 콘텐츠 계약을 모두 실행한다.
- 원문·귀속·공식 실행·영상 간선·라우트·이미지 손상, 공통 검증기 예외는 계속 전체 게시를 중단한다. 새 원문 수록까지 겹친 보류 장은 단순 롤백 대상에서 제외한다.
- 격리 상세와 비교를 Actions 아티팩트/재시도 캐시에 남긴다. 보류 문서는 정합 성공으로 승인하지 않고 재검토 대기로 기록한다. 실행 기록은 `partial`과 보류 장 목록을 제공한다.

## 검증

기존 고정 입력으로 현재 운영 본문에서 시작해 일반 BWIKI 정합 → 원문 우선 검증 → 공식 실행 투영을 재현했다. 일부 문서만 순환하는 실패 실행보다 넓게 전체 문서를 강제 재정합하여 같은 종류의 손실·연결 변경을 재현했다. 격리 후 모든 원문·기존 검증·연결·출현·순서 손실은 0개이고, 다른 장의 개선 후보는 유지됐다. 재현 후보는 운영에 직접 반영하지 않았다.

최종 계약 2,840개 본문·67,651행과 영어/중국어/일본어 투영 검사를 통과했다. Node 테스트 119개가 통과했으며, 새 4개 검사는 장 격리/다른 장 개선 보존, 원문 및 공식/영상 간선 손상 차단, 실행 출현 불변성과 표시 배치 복구, 신규 수록 혼합 차단을 다룬다.
