# HSR Archive 데이터 접근 보호 — 격리 구현 결과

운영 사이트·저장소 공개 범위·main 배포 workflow는 변경하지 않았다. 아래 보호 결과는 **격리 브랜치의 로컬 빌드/Cloudflare workerd 검증 결과**다. 실제 공개 사이트의 기존 JSON은 아직 다운로드 가능하다.

브랜치: `feature/data-access-protection`. 최신 GitHub 기준은 `5a806efc0869528f5b46735ec608498d579b8022`였고, 같은 커밋의 마지막 성공 예약 배포 `39702559290`을 확인했다. 마지막 성공 배포 snapshot을 checksum 검증하여 격리 폴더에 복원했다. 원래 작업 폴더의 미커밋 JSON 3개와 미추적 이미지는 그대로 보존했다.

최종 로컬 후보 release: `978e54ce54953f495c9d33e3ab3418a845ef8dcfc8a64ab2e72b9b4529594f53`. 검증된 동일 산출물 검사와 보호/기존 정적 빌드가 모두 통과했다. 실제 운영 API origin으로 전환할 때는 새 후보를 생성하고 다시 검사해야 한다.

## 브라우저 확인

- 기존 임무 목차와 북마크 추가 → 새로고침 후 북마크 유지.
- 원문 한 페이지50행, 이전/다음 페이지, 전체 표시 출현 수 유지(예: 원문1,245행의 반복 포함 표시1,246행).
- 한국어와 영·중·일 비교, 문맥과 선택지 응답, `dialogue`/`occurrence` 링크 이동과 해당 행 강조.
- 서적 범위 검색 `나`: 988개 결과 중 현재50행과 번역150개 표시, 오류/제한 없음. 서적 원문 링크에서도 동일 행과 세 언어 표시.
- 자료실 갱신 기록1에서 기본 기록으로 전환: 서로 다른 원래 행 ID와 세 언어 비교 유지.
- 390×844 모바일 viewport에서 가로 넘침 없음. 임시 viewport는 검사 후 해제했다. 브라우저 콘솔 오류 없음.
- 스크린샷 도구는 캡처 오류를 반환하여 이미지 증거는 만들지 못했다. 위 화면 검증은 실제 브라우저 DOM/제어와 viewport 측정에 근거한다.

## 노출 전후 비교

| 검사 | 현재 운영 | 보호된 로컬 산출물/API |
| --- | --- | --- |
| 한국어 전체/장 JSON | 200, 경로 열거 가능 | 공개 dist에 없음, Worker 부분 조회만 |
| 다국어 전체 수록본 | 언어/장 파일 순회 가능 | 요청 언어/행 ID만 반환 |
| 검색 인덱스 복원 | 전체67,000여 행 원문 파일 | D1 검색50개 결과만 반환 |
| 전체 선택지·출현 그래프 | 장 파일/증거/복구본으로 가능 | 현재 행·문맥의 연결만, 전체 graph route 없음 |
| 복구 snapshot | 공개 gzip200 | R2 private + 내부 bearer 인증 |
| JS/map/SW | JS에 일부 blocks 포함, 조사한 map/SW404 | 본문 canary/파일 허용 목록 검사 통과, map/SW 없음 |
| 연속 자동 요청 | 정적 파일에 애플리케이션 한도 없음 | workerd에서 동시 burst의 초과 요청429 확인 |
| Pages 원본 우회 | 현재 가능 | 보호 dist에는 우회 파일 없음. 실제 Pages 주소 재검사는 운영 전환 후 필요 |

공개 산출물은 이미지·CSS·JS·HTML과 허용 메타데이터를 포함한37개 파일이다. 검증한 후보와 공개 dist/검색DB/private 객체를 hash로 고정하고 원본·코드·정책 변경을 확인한다. 후보의 SQL 한 byte를 바꾸면 업로드 전 검사에서 중단되며, 원래 bytes 복구 후 hash가 일치함을 확인했다. 실패/이전 후보와 증거는 격리 `.cache`에 보존하고 커밋하지 않는다.

## 남은 운영 검증

GitHub Free의 private project Pages는 지원되지 않는다. 사용자 확인과 [공식 Pages 조건](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)에 따라 즉시 비공개 전환하면 현 사이트가 중단된다. 기존 URL 유지안은 공개 사용자 Pages 저장소의 `/hsrArchive/`에 보호 dist만 게시하고 원본은 private로 두는 방식이다. 별도 저장소는 아직 생성하지 않았다.

새 계정 연결 전이라 실제 Cloudflare quota/성능/과금, 54MB snapshot의 원격 업로드·복구, 공개 프런트 저장소 배포, CDN의 기존 파일 제거 및 API 장애 시 실제 롤백은 검증하지 않았다. 이를 로컬 성공으로 대체하지 않는다. 외부 TextMap·과거 공개 커밋·브라우저 캐시·제3자 복사본 회수는 보장하지 않는다.
