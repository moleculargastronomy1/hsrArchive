# 제4장 제8막 전체 원문 역검색 격리 실험

2026-10-21. 새 BWIKI 출현 위치 기반 매칭을 격리 데이터에서 실행하고, 사용자가 제공한 TXT로 결과를 독립 평가했다. **운영 반영·사이트 배포는 하지 않았다.** 실험 코드·본문·원본과 평가 상세는 Git에서 제외한 `.local/bwiki/experiments/act8-v3-20261021/`에 보관했다.

## 최종 결과

같은 7개 고정 BWIKI 문서의 대사·선택지 3,114곳이 분모다. 미해석 블록 229개·경계 216개·장면 설명 162개는 별도이며 이 수록률로 게임 전체 완료를 표현하지 않는다.

| 판정                                         | 출현 위치 |  비율 |
| -------------------------------------------- | --------: | ----: |
| 기존 시스템의 텍스트 연결                    |     1,383 | 44.4% |
| 새 실험: 공식 ID를 하나로 좁힌 내용 연결     |     2,780 | 89.3% |
| 새 실험: 한국어 내용 일치, 공식 ID 복수 후보 |       121 |  3.9% |
| 새 실험: 미연결                              |       213 |  6.8% |

새 방식으로 내용을 대응시킬 수 있는 범위는 2,901곳(93.2%)이나, 그중 121곳은 ID 확인 완료가 아니다. 공식 ID 연결 수를 비교하면 기존보다 1,397곳 늘었다. 이전 사이트 행의 판정을 수정한 결과가 아니라, 별도 실험 출현 위치에 대한 재판정이다.

문장·화자·종류 중복 제거 2,921개에서는 ID 후보가 유일한 2,732개, 내용만 일치한 48개, 미연결 141개다. 기존 본문에 없던 공식 원문 후보 1,346개를 찾았다. 이들은 BWIKI의 공식 장·임무 시리즈 귀속으로 확인한 표시 후보이며, 원래의 세부 임무 ID를 추측해서 만들지 않았다.

## 적용한 방식과 제외한 방식

- 전체 공식 TalkSentenceConfig와 중국어·한국어 TextMap을 같은 고정 커밋에서 Git blob 검증했다. BWIKI 문서의 임무 유형·명칭·시리즈와 공식 챕터 104010·MainMission 귀속도 확인했다.
- 전역 중국어·화자·한국어가 유일한 정확 일치 2,760곳, 기존 번역 내용 검토 11곳, 명시된 게임 성별 치환의 표시형 대조 9곳을 연결했다. 화자나 일반 대명사의 의미를 임의로 바꾸지 않았다.
- 같은 한국어 내용에 여러 대사 ID가 대응하는 경우, 하나를 임의 선택하지 않고 모든 ID 후보를 유지했다. 반복 문장은 서로 다른 출현 위치로 보존했다.
- 문장 분할·병합은 모든 내용을 빠짐없이 이어 붙인 유일한 대응만 허용했다. 최소 내용 길이·화자·분기 경계 조건을 추가한 최종 실험에서 실제 채택은 0곳이다. 점수 기준을 낮춰 억지로 채택하지 않았다.
- 첫 병합 실험에서 `……`처럼 정규화 후 빈 내용이 된 줄을 옆 문장에 흡수하는 결함을 발견했다. 1차의 2,880곳 수치는 폐기했고, 관련 원본 결과를 `v1-naive-merge.rejected.json`으로 보관했다. 최종 수치는 이 결함 수정과 ID 모호성 분류 후의 값이다.
- 확인되지 않은 화자 별칭이나 의미 유사도를 이유로 자동 연결하지 않았다. 남은 대사·선택지 213곳은 복수 ID/상이한 한국어 118곳과 정확한 후보 없음 95곳이다.

## TXT 독립 평가

실험 결과를 먼저 고정한 뒤 제공된 TXT를 읽었다. TXT는 후보 생성·번역 검토·공식 원문 수정·장 귀속·운영 검증 소스로 사용하지 않았다. 실험 파일 SHA-256은 `8fa3502fefa481c4a6ecba67f56480e7f83a472a7cd3add9609bbd5b20bd8f4d`, TXT SHA-256은 `7953829ee4b9832a20ffd23f41ff26d95686667656d17a642bcbc00de6805e24`이다.

| 항목                                         |  결과 |
| -------------------------------------------- | ----: |
| 시간표가 있는 유효 자막 줄                   | 2,719 |
| 자막 시각 역행으로 분리한 구간               |     3 |
| 평가 대상 고유 긴 발화                       | 1,527 |
| 정확히 관측한 발화                           |   212 |
| 정확히 관측했지만 참조 안에서 반복되는 발화  |     4 |
| ASR 표기 차이가 있는 유사 후보               |   237 |
| 이번 자막에서 관측하지 못한 발화             | 1,074 |
| 출현 위치까지 모호하지 않은 정확한 순서 앵커 |   211 |
| 명시된 같은 경로에서 비교 가능한 순서 쌍     |   721 |
| 위 순서 쌍의 역전                            |     0 |

ASR 유사 후보 237개는 추가 검증 완료 수가 아니다. 높은 유사도와 낮은 유사도의 표본을 읽었을 때 고유명사 오인식·단어 끝 누락·인접 자막 혼입이 확인되어 정확 일치 앵커에 합산하지 않았다. 경로가 없어 비교하지 않은 앵커 쌍 14,836개도 순서 통과로 세지 않았다.

선택지·무더빙·화면 전용 텍스트가 자막에 없다는 이유로 누락이나 실험 실패로 판단하지 않았다. 자막 전체가 제8막 모든 분기를 포함한다고 가정하지 않았다. 시간표가 없는 27줄도 별도로 조사했으며, 그중 길이 기준을 충족한 12개 내용에서 7개를 실험본과 정확히 대조했고 5개는 정확 일치를 확인하지 못했다. 이들은 시각 순서 판정에 사용하지 않았다.

평가 가능한 발화의 내용과 국소 순서는 대체로 자연스럽다. 이 결과만으로 모든 선택지·무더빙 장면·장면 전환·전체 실행 순서를 검증했다고 볼 수 없다.

## 배포 보류 사유

순환 0개·형제 분기 사이 잘못된 간선 0개다. 다만 보존된 공식 실행 연결과 BWIKI의 인접 순서가 다른 구간이 1개 있다.

- 발화: 「이 흩어진 두루마리들에는 끔찍한 내용이 기록되어 있는데, 방 안에 가득 쌓여 있어」.
- 기존 공식 연결은 「*우리*는 여기 남아서 이것들을 정리해야 해」로 이어진다.
- BWIKI는 그 사이에 다른 화자의 「무섭기도 하고 슬프기도 해! 트리앤의 날개 덕분에 살았어…」를 둔다.

이는 병렬 발화·타임라인 교차 때문일 수도 있으므로 BWIKI나 공식 연결 중 어느 쪽이 틀렸다고 단정하지 않는다. 해당 교차 발화는 제공된 TXT에서 관측하지 못했다. 실제 장면/실행 합류를 확인하기 전에는 기존 검증을 덮어쓰지 않는다.

또한 14개 BWIKI 출현 위치가 기존 행 참조 15개와 선택지/대사 역할이 다르다. 출현 위치와 원문 행을 분리한 읽기 지원 및 검토가 필요하며, 원래 행의 종류를 무단 변경하지 않았다. 121곳의 ID 모호성도 확정 연결과 구분해야 한다.

따라서 사용자의 조건에 따라 **실험 데이터로만 유지하고 배포하지 않는다.** 운영 본문·검증 정책·영상 출처 설정은 변경하지 않았다. 기존의 무관한 로컬 변경도 유지했다.

## 검증 및 산출물

실험 전용 테스트 7개를 통과했다. 빈 정지 기호의 잘못된 병합, 화자/선택지 경계 침범, 불완전·복수 분할, 성별 치환 외 내용 변경, 형제 분기의 응답 혼입, 내레이션/조건 탭 경계 침범, 숫자·부정의 평가 정규화 손실과 공식 실행 충돌을 검사했다.

격리 폴더에 실험 스크립트·테스트·고정 결과 JSON·출현 그래프·구조 감사·TXT 대조 상세·게시 보류 결정, 읽기용 한국어 TXT, 신규 공식 원문 후보 1,346개, 미연결 213곳, 내용만 일치한 121곳을 각각 저장했다. 외부 원본과 사용자 TXT 내용은 저장소에 커밋하지 않는다. 이 보고서와 집계 JSON만 동기화하며 보고서 전용 커밋은 사이트 배포를 실행하지 않는다.

게임 원문의 권리는 HoYoverse 및 해당 권리자에게 있다. BWIKI 편집·정리 정보는 BWIKI 기여자의 CC BY-NC-SA 4.0에 따른 파생 정보이며, 원문·고정 수정 번호·문서 해시는 격리 실험에 보존했다.
