정책 5는 기존 공식 원문 인덱스에 화자 없는 내레이션 역할을 추가한다. BWIKI 내레이션과 공식 중국어·한국어·TalkSentence ID가 유일하게 대응하면 검증된 BWIKI 임무/장면 위치에 수록한다. 공식 실행 호출은 필수 조건으로 사용하지 않는다. 기존 일반 대사·선택지의 대응 기준과 BWIKI 본문 순서는 유지한다. 공식 ID가 없는 무대 지시문, 여러 ID가 대응하는 문장, 화자 있는 대사와의 역할 혼동은 미확정으로 보존한다. 새 번역은 생성하지 않는다.

`source-first.mjs`, 표준 콘텐츠 갱신과 정기 재시도가 같은 Python 검증기를 호출하므로 수동/예약/재시도 경로에 영구 적용된다. 정책/코드 해시가 바뀌어 기존 보류 결과 체크포인트를 재검증한다. 개별 문장이나 제8막에 대한 수록 예외는 추가하지 않았다.
