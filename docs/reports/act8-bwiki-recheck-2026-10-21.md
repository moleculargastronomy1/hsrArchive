## 기준 완화 후보 조사

순서 미확인 356행을 대상으로, 현재 장의 공식 중국어 본문·화자·종류와 파싱한 7개 BWIKI 문서의 같은 키를 비교했다. 다음은 **후속 검토를 위한 분류**이며 확인 완료 수나 각 행의 최종 실패 원인 집계가 아니다. 위키 키는 기존 서식·공백·문장부호 정규화를 공유하며 같은 장 밖의 ID는 가져오지 않았다.

기존 `미지원 장면 내용` 검토 기록은 실제 미지원 위키 문법 외에도 `supported_runs`가 누락·모호한 매칭을 경계로 바꾼 결과를 포함한다. 해당 기록 수를 대사 누락 수나 문법 오류 수로 해석하면 안 된다. 위 표는 변경 전 후보 분류이며, 적용 후 순서 미확인 184행은 각각 공식 후보 여러 개 97행·고유 일치 후보 15행·정확한 키 없음 28행·BWIKI 반복 위치 44행이다.

완화 후보는 원문·ID의 정확한 일치를 유지하면서, 연결되지 않은 선택지나 반복 위치 때문에 주변의 고유한 일치 대사까지 보류되는 범위를 줄이는 것이다. 반복 문장은 같은 임무·분기의 명시적 실행 연결과 앞뒤 고유 앵커로 유일성이 증명되는 경우만 검토할 수 있다. 단순 배열 위치, ID 접두사, 문장 유사도는 근거로 사용하지 않는다. 장면 지시·접힌 추가 대화·조건 탭을 건너 응답을 연결하지 않는다.

모호한 위치만 경계로 남기고, 정확하게 연결한 고유한 부분 그래프를 보존하도록 구현했다. 불명확한 응답이 있는 선택지의 고유 문구는 응답 연결 없이 독립 구간으로 수록한다. `:` 문장은 공식 내레이션과 정확히 일치하는 경우에만 독립 수록하며, `span` 표시 태그와 `{{=}}` 문법도 지원한다.

## 번역 내용 대조

`editorial/bwiki-translation-matches.json`의 11개 기록은 BWIKI 중국어 발화를 한국어로 번역한 뒤 수록된 한국어 원문 자체와 비교한 결과다. 주변 사건의 맥락만으로 선택하거나 자동 유사도 점수를 판정 기준으로 쓰지 않았다. 10개는 중국어의 `他/她` 병기와 공식 성별 치환의 차이이며, 1개는 게임 발화 뒤에 BWIKI 편집자 부연이 붙은 경우다.

각 기록은 공식 대사 ID·종류·화자·중국어·한국어 전체 해시와 위키 고정 수정 번호·전체 문서 해시, 번역문·판단 사유를 포함한다. 수록된 한국어와 공식 귀속은 수정하지 않는다. 같은 장에서 공식 후보가 여럿이면 이 경로로 채택하지 않으며, 실제 본문이나 위키 수정본이 달라지면 이전 검토를 자동 확장하지 않는다. 추가된 행에는 `번역 내용 대조` 표시를 붙인다.

내용 차이가 있는 후보는 보류했다. 예를 들어 `저장`과 `……`, `PhiLia093=복숭아`와 `PhiLia…093……`은 일부 표기가 겹치지만 한국어로 번역한 발화 내용이 같지 않아 연결하지 않았다.
