# BWIKI 위치 기반 검색 문맥 보완

검색 결과의 `앞뒤 대사`가 검색용 원문 행의 옛 `review` 경계에서 멈추던 문제를 수정했다. 전체 검색에서도 선택한 장 본문을 지연 로딩하고 본문과 같은 `readingRows`·`nearbyDialogue`·`choiceDialogue`를 사용한다. 검색 자료와 본문 사이에 원문·화자·종류 불일치가 있으면 합치지 않는다. 반복 원문은 출현 위치별 문맥과 `occurrence` 주소를 선택할 수 있다.

기존 `bwiki-placement.py`가 표시 전용 `contextId`를 생성한다. 내레이션 분리 때문에 서로 다른 파서 구간이 된 연속된 BWIKI 내용을 함께 읽되, 미연결 노드·실제 경계·독립 접힘/탭·조건·응답 분기에서는 멈춘다. 기존 공식 원문·ID·출현 위치·장면 ID·선택지/공식 실행 간선을 변경하지 않는다. 문맥 창에는 내부 `추가 원문 · 순서 미확인` 장면 문자열을 노출하지 않는다.

이 생성기는 기존 전체 수동·6시간 예약·재시도 경로가 공유한다. `source-first.py`의 코드 해시와 정기 검증의 알고리즘 해시에 이미 포함되어 있어 이전 코드의 체크포인트는 재검증한다. 6시간 cron과 마지막 성공본 복구·검증한 동일 산출물 배포 정책은 유지한다.

## 격리 검증

- 기존 후보 데이터를 재사용해 개척임무 36개 읽기 항목을 검증했다. 새 원문 수록은 0개이며 기존 원문/ID·위치·연결·URL 손실 및 충돌 검사는 모두 0건이다.
- 회귀 테스트 133개, 추가 체크포인트 지문 테스트 11개 및 TypeScript/정적 빌드가 통과했다. Python 묶음에는 내레이션 연속 표시, 미연결 대사/실제 경계/같은 이름의 독립 접힘/형제 응답 분리 시험을 포함한다.
- 제8막 `146793533`을 전체 검색에서 열어 `146793534`–`146793536` 내레이션과 인접 선택지가 문서 순서로 표시됨을 실제 화면에서 확인했다.
- 반복 원문 `amphoreus-records-yesterdays-tomorrow-quest-1043704-404`의 두 출현을 전환해 서로 다른 분기 문맥과 주소가 유지됨을 확인했다.
- 선택지 `146782346`은 명시된 응답 `146782347`부터 기존 연결을 사용한다.
- `146793533` 직전 BWIKI 문장 `███████无名的人，无命的人███████`은 공식 ID 후보가 복수인 상태다. 임의로 특정하거나 이 누락 경계를 넘어 문맥을 합치지 않는다.

- 구현 커밋: `5b0d3b2a3f4f365e55bbc825ca1432d90dbc5619`.
- [코드 배포](https://github.com/moleculargastronomy1/hsrArchive/actions/runs/39884053788): 성공.
- [전체 자동 갱신](https://github.com/moleculargastronomy1/hsrArchive/actions/runs/39884086134): 검증·빌드·배포 성공. 코드 변경으로 36/36 항목을 체크포인트 재사용 없이 재검증했다. CI 회귀 테스트 133/133 통과, 11,381개 파일의 검증된 복구 스냅샷을 저장했다.
- 갱신 전 운영 기준: 원문 74,425개, BWIKI 배치 원문 63,196개, 순서 미확인 원문 11,229개. 제8막 원문 2,918개, 순서 미확인 180개.
- 갱신 후 같은 수치를 유지한다. 새 원문 수록 0개, 원문/ID/귀속 변경·행 삭제·기존 연결/출현 위치 손실·순서 충돌·보류된 장과 신규 행은 모두 0건이다.
- 제8막의 BWIKI 출현 2,792개에 문맥 구간이 적용됐다. 실제 게시 데이터의 기존 출현 ID·위치·응답 간선을 전후 대조했고, 검색에서 `146793533`을 열어 내레이션 3개와 인접 선택지가 함께 표시되는 실제 화면을 확인했다. 문제 대사 앞의 미연결 경계는 유지한다.
- 기존 재시도 로그의 `newlyVerified: 1920`은 원문 행의 옛 BWIKI 상태 재대조 집계다. 이번 새 원문 수록이나 신규 BWIKI 배치 수로 계산하지 않는다.

검증 로그·재개 상태·전후 데이터·화면은 커밋하지 않는 `.cache/wiki-context/`에 저장한다. 외부 원본은 저장소에 추가하지 않는다.
