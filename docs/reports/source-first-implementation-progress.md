# 전체 개척임무 원문 우선 검증 구현 진행

사용자 승인 범위: 전체 개척임무 격리 일괄 검증, 공식 임무 귀속이 확인된 원문의 안전한 부분 반영, 자동 검증·복구가 통과한 동일 산출물의 배포. 임무별 승인을 요구하지 않는다.

## 고정 정책

- 제8막 A→B / A→X→B: 실행 범위 미확인. 실제 충돌·오탐으로 확정하지 않는다.
- 전역 원문 일치는 내용 후보이며 공식 임무 귀속을 대신하지 않는다.
- 새로운 번역 의미 대응은 후보만 기록한다. 기존 검토는 고정 수정본과 모든 공식 해시를 다시 확인한다.
- 사용자 TXT는 독립 평가 전용. 연결·귀속·순서 생성에 입력하지 않는다.
- 미확인 노드·선택지·조건·장면 경계를 건너 간선을 만들지 않는다.
- 원본·BWIKI·검증 코드·정책·기준 데이터·실행 구조·검토 기록이 같을 때만 결과 재사용.
- 공통 검증기 오류는 영향받는 자동 반영을 중단한다. 정상 임무의 검증은 개별 자료 실패와 독립적이다.
- 배포는 검사한 파일과 빌드 산출물을 해시로 고정하고 재수집·재생성하지 않는다.
