### 반영하지 않은 자막 순서

사용자 지정 K tube 재생목록의 [프롤로그](https://www.youtube.com/watch?v=SsuDCp8nYEw)에서 공개 한국어 자동 자막을 내보내 대조했다. 87개 고유한 긴 원문이 정확히 대응했다. 음성 자막으로 선택지를 확인하지 않았다. `quest-1000101`, `bwiki-page-2101`, `bwiki-page-2229`, `bwiki-page-2239`의 기존 앵커와 관측 순서가 충돌해 기존 연결을 유지했다. 충돌 원인이 선택 방문 순서인지 다른 조건인지 아직 확정하지 않았다.

직접 HTTP 자막 조회는 빈 응답으로 실패했지만 브라우저의 공개 자막 내보내기는 가능했다. 수동 확보 증거의 재사용과 Actions의 자동 자막 조회 성공 여부를 구분한다.

## 남은 대상

| 범위 | 순서 미확인 행 전 → 후 | 응답 미확인 선택지 전 → 후 |

원문은 있으나 연결 근거가 부족한 현재 수록 행의 수다. 응답이 없는 선택지에는 종료·반복·미지원 조건도 포함될 수 있어 모두 누락 대사라고 단정하지 않는다. 개척 임무 소개문 1행과 시뮬레이션 단독 설정 기록 269행은 순서 검증 완료로 세지 않았다. 현재 수록 행의 공식 한국어 연결 누락은 0건이지만 게임 전체의 미수록 원문 수를 의미하지 않는다. 공식 원문 자체의 부재와 미지원 구조·귀속 부족은 구분한다.

개척 임무의 「청천 위 교차하는 칼끝·상/하」, 「좋은꿈과 성배」는 영상 후보의 장 귀속이 미연결이다. 시뮬레이션 2차 베타·일반 우주, 곤충 떼 재난 튜토리얼·결말, 황금과 기계 시작·튜토리얼, 차분화 우주 덕성의 찬가·방정식 로딩·아하의 게임은 모드·사건·장면별 출처와 경로 검증이 더 필요하다. 검색에서 발견한 추가 후보도 실제 내용 검토 전에는 데이터에 연결하지 않았다.

모든 항목의 남은 공식 행 ID·응답 미확인 ID·출처·실패 시각·다음 대기 시각·충돌 기록은 [기계 판독 보고서](youtube-verification-2026-10-18.json)에 있다. 마지막 로컬 시험 실행은 최대 2개 영상을 조회했고 기한이 된 영상 48개를 남겼다. 한도 도달을 검증 완료로 표현하지 않는다.

## 자동 실행과 토큰

기존 GitHub Actions가 6시간마다 BWIKI와 유튜브의 독립 재시도 시각을 검사한다. 원문·목록 변경이 없어도 기한이 된 자막을 최대 2개씩 순환 조회한다. 자막 없음·접근 제한·조회 실패를 구분하고 실패 대기는 24→48→72시간으로 늘린다. 캐시와 마지막 배포 중 최신 확인 기록을 사용한다. 자막 수집·정확 매칭·증거 재검사·통합·테스트·배포는 스크립트로 실행하며 AI API를 호출하지 않는다. 정기 실행에는 Codex·AI API 토큰이 사용되지 않으며 GitHub Actions 실행량은 별도다. 이 구조를 조사·개발하고 화면을 검토하는 현재 대화 작업에는 모델 토큰이 사용된다.

새 화면·선택지의 자동 판독은 구현하지 않았다. 자막으로 확인할 수 없으면 화면 검토 대기로 남긴다. 직접 확인한 화면 증거는 현재 공식 ID·원문·역할·장면에 자동 재대조한다. 검증 실패·충돌은 기존 배포를 보존하고 접근 제한을 우회하지 않는다.

- 마지막 성공 배포의 2,454개 본문, 61,111행, 선택지 4,415개의 ID·본문·종류·화자·공식 ID·해시·원래 귀속을 Python 정수로 전후 비교해 보존했다.
