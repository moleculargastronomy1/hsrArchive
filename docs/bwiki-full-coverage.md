# BWIKI 전체 수록과 순서 검증 조건

제4장 제8막 「어제의 내일이 되어」의 2026-10-21 재검증을 기준으로 정한 후속 구현 계약이다. 현재 코드에 적용한 부분은 고유 구간 분리·독립 선택지·내레이션·번역 내용 검토이며, 이 문서의 전체 수록 및 출현 위치 그래프는 추가 구현 대상이다. 전체 수록을 모든 분기의 검증 완료와 같은 상태로 처리하지 않는다.

## 수집 대상과 완료의 분모

기존 사이트 행을 출발점으로 BWIKI에서 같은 문장을 찾는 방식만으로는 누락된 본문을 발견할 수 없다. 먼저 공식 장과 연결한 BWIKI 문서의 **모든 대사·선택지·내레이션·조건 탭·접힌 추가 대화**를 출현 위치별로 목록화한다. 미지원 문법·조회 실패·문서 없음도 목록에 남긴다. 이런 항목을 제외해 완료율을 높이지 않는다.

출현 위치의 키는 공식 장 ID·위키 문서 ID·수정 번호·구조 경로·종류·원문 해시로 구성한다. 같은 문장이 두 분기에 등장하면 두 출현 위치를 유지한다. 한국어 원문 행 ID는 원문 식별자이며 출현 위치와 일대일일 필요가 없다. 기존 행 ID·북마크·원래 귀속은 보존한다.

다음 세 집계를 나란히 제공한다.

| 집계                | 분모                               | 완료 조건                                                                               |
| ------------------- | ---------------------------------- | --------------------------------------------------------------------------------------- |
| 원문 수록           | 수집한 BWIKI 출현 위치             | 공식 한국어 행으로 연결했거나 명시적인 제외 사유가 있음. 제외는 연결 성공으로 세지 않음 |
| 국소 순서           | 같은 장면·같은 조건 안의 연결 후보 | 직접 관측한 위키 순서/분기 또는 공식 실행 구조로 연결됨                                 |
| 분기·임무 전체 경로 | 시작·종료·선택·합류·임무 전환      | 모든 경계와 경로가 확인되고 충돌·미조회·미해석 항목이 없음                              |

세 번째 조건이 충족되기 전에는 `전체 검증 완료`를 표시하지 않는다. BWIKI에 수록하지 않은 게임 분기는 별도의 범위이며, BWIKI 전체 수록으로 게임 전체 분기를 완료했다고 표현하지 않는다.

## 한국어 원문 연결

BWIKI 문서의 임무 유형·공식 임무명·시리즈가 공식 챕터/임무 카탈로그와 맞아야 한다. 같은 제목의 세부 임무가 여러 개면 문서 단위 귀속을 유지하고 임의의 세부 임무 ID를 선택하지 않는다.

원문 연결은 다음 순서로 판정한다.

1. **현재 장의 정확 일치:** 중국어 본문·화자·종류가 유일하고, 정확한 대사 ID의 공식 한국어가 일치한다.
2. **누락된 공식 대사 추가:** 현재 사이트에 없더라도 전역 TalkSentenceConfig에서 중국어·화자가 유일하게 맞고 한국어가 있으며, BWIKI 문서의 공식 장 귀속이 확인되면 새 파생 행 후보로 만든다. 숫자 접두사나 파일 배열 위치로 귀속을 추정하지 않는다. 기존 행이 같은 공식 ID를 사용하면 새 원문 행을 중복 생성하지 않고 출현 위치만 연결한다.
3. **공식 자막/내레이션:** 위키에서 자막·내레이션 역할이 명시되고 중국어 TextMap 해시가 유일하며 같은 해시의 한국어가 있을 때 연결한다. 일반 장면 지시문을 게임 원문으로 만들지 않는다.
4. **번역 내용 대조:** BWIKI 발화를 한국어로 번역하고 기존 공식 한국어 후보와 비교한다. 발화의 행동·대상·부정·수량·고유명사·시제·조건·화자 역할이 보존되고, 같은 공식 장에서 후보가 하나일 때만 검토 기록으로 채택한다. 비슷한 주제나 주변 이야기의 맥락, 자동 유사도 점수만으로는 채택하지 않는다. 편집자 부연은 실제 발화와 구분한다.
5. **복수 후보:** 같은 말을 하는 서로 다른 공식 ID가 남으면 후보를 모두 기록한다. 공식 분기 구조·명시된 조건·직접 확인한 영상 경로로 하나가 되기 전에는 임의로 선택하지 않는다. 번역해도 같은 두 ID는 번역으로 구분할 수 없다.

번역문 자체를 공식 한국어 원문 대신 수록하지 않는다. 번역 검토로 연결한 행에는 `번역 내용 대조`를 표시한다. 검토 기록에는 위키 원문과 수정 번호·문서 해시, 공식 ID·중국어·화자·한국어 해시, 번역문·판정 이유를 남긴다. 입력 변경 시 재검사하며 이전 판단을 다른 문장에 일반화하지 않는다.

## 순서와 응답 연결

텍스트가 매칭됐다는 사실만으로 해당 행 앞뒤의 순서를 확정하지 않는다. 순서는 원문 행 배열을 임의로 바꾸는 대신, 출현 위치 사이의 **범위가 명시된 방향 그래프**로 검증한다.

| 연결 종류             | 허용 조건                                                                                          | 연결하지 않는 경우                                             |
| --------------------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 같은 구간의 다음 대사 | 같은 조건·장면 내부에서 BWIKI에 연속으로 쓰인 두 대사 모두 매칭되고 사이에 누락/미해석 노드가 없음 | 중간 대사를 못 찾았거나 장면 경계를 건넘                       |
| 선택지 → 응답         | BWIKI의 해당 선택지 본문 안에 응답이 명시되고 두 출현 위치가 매칭됨                                | 번역의 자연스러움·같은 주제·단순 이웃 배열만 맞음              |
| 분기 → 공통 후속      | 위키 구조 또는 공식 실행 그래프에서 같은 합류를 명시함                                             | 서로 다른 응답의 마지막 문장이 비슷하거나 선택지 아이콘만 있음 |
| 조건별/반복 대사      | 각각의 조건과 출현 위치를 유지하고 각 경로에서 별도로 연결함                                       | 같은 원문 ID라는 이유로 서로 다른 분기를 합침                  |
| 장면 → 장면           | 명시적인 실행 연결 또는 확인한 플레이 경로가 있음                                                  | 위키 편집 순서만 있고 장면 전환 의미가 불명확함                |
| 임무 → 임무           | 공식 장 귀속과 위키의 선행/후행 임무 또는 충돌 없는 고유한 시리즈 순번이 맞음                      | 순환·중복 순번·다른 장의 임무·조회 실패                        |

문서 안의 표시 순서를 참고할 수 있어도 검증된 실행 간선과 구분한다. 접힌 추가 대화·조건 탭·이미지·장면 설명·미해석 문법은 기본적으로 독립 경계다. 선택지 문구만 확인됐으면 문구는 수록하되 응답 확인 상태를 별도로 남긴다.

미매칭 노드 하나 때문에 구간 전체를 버리지 않는다. 확인한 부분 그래프를 살리되 제거한 노드를 건너는 새 간선을 만들지 않는다. 기존에 검증한 노드·간선·상대 순서를 잃거나 공식 실행 구조와 충돌하면 새 결과의 게시를 막는다.

## 변경 후 검사와 재검토

- 수집 목록의 모든 출현 위치가 연결·후보·누락·미지원·조회 실패 중 하나로 추적되는지 검사한다.
- 텍스트 원문·ID·해시·귀속, 출현 위치의 중복, 선택지별 응답 소유, 합류와 순환을 검사한다.
- 기존 검증 그래프를 보존하고, 검색·본문·다국어가 같은 행과 출현 위치를 가리키는지 검사한다.
- 새 위키 수정본·공식 원문 변경·번역 검토 수정 시 관련 후보만 다시 검사한다. 조회 실패는 변경 없음이나 확인 완료로 처리하지 않는다.
- 게시 전에 전체/미연동 수를 **사이트 행 기준과 BWIKI 출현 위치 기준으로 각각** 보고한다. 한쪽의 분모로 다른 쪽의 수록률을 표현하지 않는다.

## 제8막에서 남은 구현 순서

현재 사이트에는 1,576행 중 1,390행이 BWIKI에 연결되어 있고 186행이 미연동이다. 반면 파싱한 BWIKI 대사·선택지는 중복 제거 2,921개 중 1,543개가 미연동이며, 반복 출현 기준으로는 3,114곳 중 1,731곳이다. 장면 설명과 미해석 문법은 별도다.

따라서 다음 작업은 기존 186행의 임계값을 계속 낮추는 것보다 **BWIKI 출현 위치 목록 → 전역 공식 대사 후보 확인 → 누락 원문 추가 → 조건별 출현 그래프 검증** 순서로 진행한다. 전체 공식 데이터에서 같은 중국어·화자를 찾은 미수록 출현 1,368곳을 먼저 조사한다. 중복 ID·타 장면 귀속·종류·한국어 유무를 확인하기 전에는 이 수를 추가 가능한 고유 대사 수로 간주하지 않는다. 세부 수치와 재현 근거는 [재검증 보고서](reports/act8-bwiki-recheck-2026-10-21.md)를 따른다.
