# 기본 뼈대와 데이터 연결 계획

시뮬레이션 모드는 시뮬레이션 우주 → 곤충 떼 재난 → 황금과 기계 → 인지 불가 영역 → 차분화 우주 순으로 표시하고, 기물 기록은 마지막에 둔다. 표시 순서는 자동 수집 결과와 별도로 유지한다.

시뮬레이션의 다섯 모드에는 기존 임무와 함께 사건 기록을 제공한다. 모드별 사건 목차, 원문·선택지·효과, 다국어 비교와 확인된 대표 이미지는 [사건 기록 연동](simulation-events.md)의 공식 귀속·검증 계약을 공유한다.

각 모드의 사건은 `모드명 - 사건 기록` 하위 카테고리에서만 목록으로 표시한다. 모드의 기본 목차와 읽기 목차에는 스토리만 표시하고, 사건 카테고리와 사건 읽기 목차에는 사건만 표시한다. 이전·다음 이동과 번호도 이 경계를 따르며 기존 장·본문·북마크 주소는 유지한다. 사건 목차 주소는 모드 주소에 `?section=events`를 붙인다. 시뮬레이션 분류의 모드 카드와 상세 제목 아래 설명 문구는 표시하지 않는다.

수집·정확 매칭·순서/분기 검증·자동 재시도·영상 통합·배포의 현재 역할과 의존성은 [수집·검증·게시 모듈 구조](verification-pipeline.md)를 따른다. 표시용 데이터 계약과 UI는 유지하며, 외부 근거의 비교와 게시 전 보존 정책을 공통 통합 단계에 둔다.

## 기본 기능

스타레일 자료를 분류별로 탐색하고 목차에서 본문으로 이동하는 흐름을 구현한다.

| 기능                        | 구현                                    |
| --------------------------- | --------------------------------------- |
| 분류별 목록과 챕터 수       | 개척 임무·시뮬레이션 우주·아카이브 목록 |
| 챕터 목록                   | 자료 상세와 챕터 목차                   |
| 목록→챕터→본문, 스크롤 복원 | 정적 호스팅용 해시 주소, 읽기 위치 저장 |
| 이전·다음 챕터              | 경계에서 이동을 제한하는 챕터 탐색      |
| 로컬 테마 저장              | 라이트·다크 테마 저장                   |
| 주 메뉴와 모바일 메뉴       | 사이드바와 모바일 탐색                  |

추가로 본문 검색, 북마크, 읽기 기록, 글자 크기 조절을 기본 뼈대에 구현했다. 음성 기능과 게임별 특수 콘텐츠는 자료 확보 후 별도로 설계한다.

## 사이트 데이터 계약

`src/data/types.ts`의 `ArchiveEntry`는 **사이트 내부 표시용 계약**이다. 실제 추출 도구의 출력 형식으로 확정한 것이 아니다.

- 자료: 고유 ID, 제목, 설명, 분류, 지역, 순서, 언어, 태그
- 출처: 현재 `demo`, 검증된 추출 자료는 `extracted`와 게임 버전·원본 ID
- 챕터: 안정적인 ID와 제목, 순서대로 정렬한 블록
- 블록: 고유 ID, `narration` 또는 `dialogue`, 화자, 텍스트

본문은 React 텍스트 노드로 표시해 문자열을 HTML로 실행하지 않는다. 공식 데이터의 서식 태그, 분기, 선택지, 성별·주인공 이름 치환, 다국어와 음성 ID는 실제 입력을 확인한 뒤 계약을 확장해야 한다. 현재 계약은 그런 요소를 변환하거나 보존한다고 보장하지 않는다.

## 추출·변환을 연결하기 전에

1. 게임 버전과 언어, 원본 입력 파일의 종류를 확인한다.
2. 추출 도구의 지원 입력과 실제 파일의 호환성을 검증한다.
3. 소량의 실제 출력으로 텍스트 ID, 챕터 순서, 화자 참조, 분기와 서식 보존 방식을 확인한다.
4. 검증한 입력 형식 전용 변환기를 추가한다. 미지원 형식은 조용히 누락하지 않고 오류를 반환한다.
5. 원본 출처와 버전을 기록한 사이트 데이터를 생성하고 예시 데이터와 교체한다.

게임 바이너리 추출기는 실행하지 않았으며 현재 게임 입력의 호환성도 검증하지 않았다. 이후 고정된 로컬 한국어 JSON을 검증해 사이트 본문으로 변환하는 경로를 구현했다. 실제 지원 스키마와 연결 규칙은 `docs/content-import.md`를 따른다.

## 후속 확장

아카이브의 7개 분류는 공통 `ArchiveEntry` 계약으로 검색과 북마크에 연결하고, `CodexReader`에서 목록 검색과 항목별 원문 읽기를 제공한다. 분류 아이콘은 `CategoryIcon`에서 공통으로 표시한다. 아카이브 심볼은 기존 별·궤도·책 모티프를 얇은 선으로 재구성한 `src/assets/archive-line.svg`를 사용하며, 홈과 사이드바에서 현재 메뉴 색상을 따른다.

홈은 `HomePage`에서 원문 검색, 네 가지 자료 분류 바로가기, 장 순서의 개척 임무 목록을 제공한다. 이어 읽기·공지·공식 영상은 PC에서 오른쪽 보조 영역, 좁은 화면에서는 목록 아래에 표시한다. 검색·북마크·읽기 위치는 기존 공통 상태와 주소를 공유하며, `Ctrl+K`는 홈의 주 검색창으로 이동한다. `site.css`의 남색·금색 테마와 공통 사이드바·목록을 모든 화면에 적용하고, `pages.css`에서 검색·임무 목차·본문·자료실·서적·서재·안내 화면의 간격과 글자 크기를 정리한다. 본문은 단색 배경으로 표시하며 우주 배경과 궤도 장식을 사용하지 않는다. 첫 방문은 다크 모드이고, 상단의 별도 다크·라이트 버튼에서 선택한 테마는 `hsr:theme`에 저장해 다음 방문에도 유지한다. `index.html`에서 저장된 테마를 먼저 적용해 초기 화면의 밝은 깜박임을 방지하며, 저장소를 사용할 수 없어도 기본 다크 모드로 정상 동작한다.

목록 메타데이터와 챕터 본문을 분리하고 본문을 지연 로딩한다. 전체 검색 자료는 검색 화면에서만 불러온다. `ArchiveEntry` ID와 챕터 ID는 북마크·읽기 기록의 키이므로 데이터 갱신 시 안정적으로 유지해야 한다. 읽기 기록은 마지막 장·대사 페이지·픽셀 스크롤 위치이며 읽음 완료 상태를 뜻하지 않는다.

개척 임무·시뮬레이션 우주·아카이브 목록은 이미지 위·설명 아래의 액자형 카드 배열을 기본으로 제공한다. 우측 기록 수 위의 작은 보기 버튼에서 기존 가로 목록형으로 전환하며, `hsr:archiveLayout`에 선택을 저장해 분류 이동과 재방문에도 유지한다. 지역 필터·자료 링크·북마크는 같은 자료와 상태를 공유한다. 홈과 서재·서적의 기존 목록 배치는 유지한다.

## 다국어 동시 비교

임무 본문의 `nextIds`·`replyToIds`·`flowScene`은 검증한 장면 내부의 대사 연결이며 전체 임무의 플레이 순서를 뜻하지 않는다. `flowStatus`로 확인 상태를 표시하고, 선택지를 누르면 기존 배열의 이웃 대신 명시적으로 연결된 응답을 조회한다. 누락 경계와 다음 선택지에서 멈추며 다른 선택의 응답을 해당 경로에 섞지 않는다. 기존 행 ID를 유지하므로 북마크·읽기 주소·다국어 비교 연결을 보존한다. 복원 및 확인 대상 기록은 `docs/content-import.md`를 따른다.

BWIKI 대조는 `bwikiNextIds`·`bwikiReplyToIds`·`bwikiScene`과 `bwikiStatus`로 별도 기록한다. `matched`는 이번에 조회한 문서와 정확히 연결한 상태, `cached`는 이전 문서의 파생 연결을 현재 공식 원문에 재검증한 상태, `review`는 연결을 확정하지 않은 상태다. 선택지 응답 화면은 대조한 BWIKI 구간이 있으면 그 분기를 사용하며 구간 경계·다음 선택지에서 멈춘다. 문서의 고정 수정 버전 링크와 라이선스·가공 사실을 표시한다.

목차 목록의 본문 안내는 `2,477줄`처럼 줄 수만 표시한다. 읽기 상단에서는 BWIKI 관리 본문의 대조 안내 대신 원문 줄 수와 언어를 표시한다. 장면 연결·BWIKI 대조 요약과 출처·라이선스는 읽기 화면의 이전·다음 장 탐색 아래 `자료 출처` 접힌 영역에 표시한다. 목차 하단의 자료 출처도 같은 기본 접힘 디자인을 사용한다. 수집 기록과 검증 메타데이터는 그대로 유지한다. 실제 본문이 있는 장의 예시 대사 영역은 표시하지 않는다. BWIKI에서 명확하게 연결한 임무 귀속은 `bwikiMissionId`·`bwikiMission`으로 별도 보존하며 원래 출처 정보 대신 읽기 화면의 임무명과 분기 경계에 사용한다. 게임의 `{RUBY_B#주석}본문{RUBY_E#}`은 공통 `GameText`에서 본문 위 작은 주석으로 표시하며 원본 데이터와 검증 해시는 바꾸지 않는다. 한국어·비교 언어·앞뒤 대사·자료실·서적에 같은 표시 규칙을 적용한다. 주석에 미해결 게임 치환 토큰이 있으면 본문만 표시하고 주석을 추정하지 않는다. 검색은 표시 본문과 주석을 대상으로 하며 태그 때문에 이어진 본문 검색이 끊기지 않게 한다.

앞뒤 대사 창은 선택한 대사의 같은 장면 안에서 최대 앞뒤 20줄을 표시한다. `선택한 대사로`는 창을 닫고 해당 대사가 속한 임무·장 본문으로 이동한다. 주소의 `dialogue` 매개변수에 안정적인 행 ID를 담아 해당 페이지를 연 뒤 원문을 강조하고 스크롤하며, 저장된 읽기 위치보다 이 이동을 우선한다. 자료실·서적도 해당 항목과 기록을 열어 같은 행을 표시한다. 선택지 응답은 명시적으로 연결된 경로를 최대 41줄 표시하고 다음 선택지와 누락 경계에서 멈춘다. 이전·다음 줄 넘기기 버튼은 제공하지 않는다. BWIKI 대조 안내 문구는 창 본문에서 제거하고 기존 하단 출처·라이선스는 유지한다.

읽기 화면의 `한국어 원문 · 선택지 포함` 옆 `언어 추가`에서 영어·중국어(간체)·일본어를 여러 개 추가한다. 한국어를 유지하면서 같은 행의 원문을 함께 표시하고, 언어별 닫기 버튼으로 제거한다. 선택 언어는 로컬에 저장한다. 자료실 원문·갱신 기록, 전체 검색과 앞뒤 대사에서도 같은 비교 기능을 제공한다. 넓은 화면에서는 열을 나란히 배치하고, 중간 화면은 두 열, 모바일은 언어별로 이어서 표시한다.

비교 원문은 `public/content/locales/{en|zh-CN|ja}/{entryId}--{chapterId}.json`에 저장하며, 선택한 언어와 현재 페이지·문맥에 필요한 장만 지연 로딩한다. 한국어 검색 자료에 외국어 전체 본문을 포함하지 않는다. `hsr-localizations.v1`은 언어·장 ID·참조 커밋과 `{id, speaker, text}` 행을 담는다. 위치 대신 한국어 행 ID로 연결해 선택지·분기·갱신 기록이 뒤섞이지 않게 한다. 일치 원문이 없는 행, 로딩 중, 조회 실패와 재시도를 각각 표시한다.

## 신규 개척 임무 자동 연결

`src/data/trailblaze.json`에 저장된 목록이 있으면 정적 개척 임무 목록 대신 사용하고, `imported-content.json`의 최신 본문 메타데이터를 연결한다. 기존 장 ID와 주소·예시 블록은 보존한다. 한국어 제목으로 처음 연결한 뒤에는 `upstreamChapterId`로 같은 장을 식별한다. 새 장 ID는 `chapter-{공식 챕터 ID}`이며, 아직 지원 지역이 없는 새 개척 편은 `universe` 아래 별도 목록으로 제공한다. 구조가 확인되지 않은 장은 소개문만 표시하고 `contentNote`로 상태를 안내한다. 자동 연결 결과도 같은 전체 검색·읽기·다국어 계약을 사용한다.

## 인게임 서적

`books` 분류를 개척 임무·시뮬레이션 우주·아카이브와 나란히 제공한다. 왼쪽 서적 메뉴에서 지역별로 이동하며, `CodexReader`의 시리즈·권 목록에서 제목 검색과 책장 수록/기타 문서 필터를 사용할 수 있다. `Chapter.group`은 시리즈 이름, `collection`은 책장 수록 여부다. 전체 원문 검색·북마크·읽기 기록·다국어 비교는 기존 계약을 공유한다. 입력·수록 범위·갱신 규칙은 [인게임 서적](books.md)에 기록한다.

소개문만 있던 장은 BWIKI의 공식 챕터·임무 시리즈를 확인하고 유일한 공식 대사 ID 또는 명시된 자막의 TextMap 해시로 부분 본문을 수록한다. 조건별 탭·미연결 선택지의 본문은 독립 구간으로 표시한다. 상세 기준은 `docs/content-import.md`를 따른다. 한국어 플레이 영상의 자막 대조는 BWIKI 다음 단계이며 원문 일치와 앞뒤 앵커를 확인한 순서만 반영한다. 해당 장의 영상 링크와 대기/대조 상태는 하단 접힌 안내에만 표시한다.
