# 업데이트별 한국어 텍스트 확보 경로

확인일: 2026-10-16 (Asia/Seoul).

## 릴리스 입력

원문 자동 갱신은 [DimbreathBot/TurnBasedGameData](https://github.com/DimbreathBot/TurnBasedGameData)의 한국어 TextMap, 임무·챕터 표, 대사 표와 제공되는 스토리 구조를 입력으로 사용한다. 확인한 릴리스 커밋은 `312b4597691e0a29cf9828a15b592757dba86949`, 버전은 `OSPRODWin4.6.0_D16728363_A16704710_L16700845`이다.

커밋 목록에서 릴리스 버전 문자열을 확인하고, 사용할 커밋을 고정해 필요한 파일만 받는다. 매 버전의 모든 장면·대사 수록이나 갱신 시점을 보장하는 서비스는 아니다.

한국어 문자열만 있어서는 임무별 읽기 순서를 만들 수 없다. `MissionChapterConfig` → `MainMission`의 챕터 귀속, 스토리·장면의 명시적 대사 참조 → `TalkSentenceConfig` → 한국어 TextMap을 연결하고 선택지와 화자를 보존해야 한다. 해시는 Python 정수로 처리한다. 연결 근거가 없는 문자열과 숫자 접두사 일치는 임무 대사로 수록하지 않는다. 입력의 커밋·Git blob·SHA-256과 수록 범위를 기록한 뒤 검증을 통과한 사이트용 결과만 커밋한다.

기존 임무별 한국어 자료는 고정된 로컬 입력을 검증·변환한 결과다. 입력 형식과 재생성 명령은 [본문 연결과 검증](content-import.md)을 따른다.

## 현재 제7막의 한계

한국어 TextMap에 제7막 관련 문장 자체는 존재한다. 사용자가 제공한 해시 `318073619201285988`은 `TalkSentenceConfig` 대사 ID `156000402`와 정확히 연결된다. 다만 문자열·대사 ID의 존재만으로 전체 임무의 장면 순서나 선택지 연결을 알 수는 없다.

4.6 챕터 표에서 `105009`의 제목과 소개문, `MainMission` 표에서 관련 임무 ID는 확인했다. 그러나 해당 고정 버전 `Story/Mission`에는 `1054600` 등의 제7막 구조가 없고, 현재 로컬 한국어 입력에서도 제7막 임무에 귀속된 대사를 찾지 못했다. 따라서 현재 사이트에는 목차와 소개문만 표시한다.

소개문을 재생성하려면 위 고정 커밋의 `ExcelOutput/MissionChapterConfig.json`과 `TextMap/TextMapKR_0.json`, `TextMap/TextMapKR_1.json`을 `.cache/astro-source`에 파일명 그대로 준비하고 `python scripts/import-astropolis-intro.py`를 실행한다. 이 스크립트는 고정된 Git blob 해시를 확인한다.

게임 바이너리 추출기는 실행하지 않았으며 현재 게임 입력과 추출 도구의 호환성은 별도 검증해야 한다. 게임 원문과 이미지의 권리는 해당 권리자에게 있다.

신규 개척 임무 자동 연결기는 같은 기존 원본의 제목·챕터 ID·소속 임무·공개 JSON 구조를 확인한다. 현재 커밋에서 기존 본문 28개 챕터를 유지하고 제7막 1개 챕터를 연결 대기로 기록했다. 지원 구조가 확보되면 같은 읽기 주소에서 본문으로 전환하며, 공개 구조가 없는 동안에는 소개문을 유지한다. 입력 해시와 임무별 구조 누락 사유는 `public/trailblaze-provenance.json`에 기록한다.
